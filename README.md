# Báo cáo tuần VKSND tỉnh Ninh Bình

Ứng dụng nhận file Excel báo cáo tuần và tạo file Word theo mẫu báo cáo tuần 09/9/2026.

Chức năng chính:
- Tổng hợp số liệu các sheet nghiệp vụ.
- Tổng hợp Hoạt động kiểm sát.
- Tạo footnote từ dữ liệu/ghi chú có cấu trúc.
- Cập nhật phụ lục chỉ tiêu.
- Xuất file DOCX theo mẫu chuẩn.

Triển khai trên Render bằng Python/Flask + Gunicorn.
